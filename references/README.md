# 本地资料规则

本目录用于记录项目开发过程中需要查阅的本地参考资料规则，不作为第三方文档的公开分发目录。

公开 Repository 中：

- 官方 Datasheet、Reference Manual、Application Note 等优先通过根 `references.md` 记录 manufacturer、part number、官方链接与用途；
- 用户提供或供应商提供的第三方 PDF 可以用于开发和证据核对，但默认不随公开仓库重新分发；
- 商品页、分销商页只能作为采购或 point-in-time availability 证据，不能替代官方技术资料；
- 关键结论仍应在 `references.md` 中记录来源、允许用途和 evidence boundary。

因此，本目录允许在本地工作区存在未提交的参考 PDF，但公开仓库原则上只保留索引与来源信息，不要求归档第三方原始文件。
