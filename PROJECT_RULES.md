# Project Rules

Project: LiIon Charger Protection Board
Repository: `wum747349-debug/LiIon-Charger-Protection-Board`
Default branch: `main`

## Authority

This repository is the active standalone project authority. Historical migration sources are reference-only.

## Rules

- Keep changes scoped to the requested task and preserve unrelated work.
- Current authoritative EDA / manufacturing / hardware evidence wins over stale notes.
- Do not treat design targets, datasheet capability, calculations, planned tests or expected behavior as measured PASS.
- Do not change Framework binding, Project Stage, Gate state or project structure unless explicitly required.
- Prefer maintaining existing authoritative records instead of creating duplicates.
- Record actual Stage 8 measurements, failures, fixes and retests in the active Bring-up record.
- Real battery connection requires physical mating and measured polarity / wire-order verification first.
